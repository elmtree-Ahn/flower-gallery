# 꽃 탐험대

초등 5학년 과학 '꽃의 구조' 수업용 웹앱.

- **꽃 분해하기**: 백합·장미·철쭉을 눌러서 한 조각씩 떼어 보고, 꽃받침·꽃잎·수술·암술을 칸에 모아 관찰합니다.
- **여러 가지 꽃**: 갈래꽃, 통꽃, 모여 피는 꽃, 바람·새가 돕는 꽃 13종을 실제 사진으로 봅니다.

장미 이야기는 수상한생선 Life Science의 [장미 해부 영상](https://www.youtube.com/watch?v=8-eQrRayqk0)을 참고했습니다.
